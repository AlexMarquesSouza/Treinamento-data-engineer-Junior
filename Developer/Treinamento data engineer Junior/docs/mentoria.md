# Guia rápido para o mentor

## Como manter o foco

- Trabalhe em ciclos de duas semanas com objetivo visível e poucas tarefas em andamento.
- Escolha 8–12 exercícios por semana conforme dificuldade; os 40 de cada nível são banco de prática, não meta de velocidade.
- Faça o aluno estimar, implementar, testar, abrir PR e refletir.
- Limite a teoria: uma fonte principal e uma de referência por tópico.
- Use revisão espaçada: repita conceitos após 1, 7 e 30 dias em contextos diferentes.
- Reserve exercícios não vistos para avaliação; não use apenas os que ele já decorou.

## Perguntas de revisão

- Qual é a entrada, saída e contrato?
- O que acontece se executar duas vezes?
- Como sabe que não perdeu nem duplicou dados?
- Como o erro aparece e quem deve agir?
- Onde estão as credenciais?
- Qual é o grão do dado?
- O que muda se o volume crescer 100 vezes?
- Como retomar depois de falhar no meio?
- Que teste detectaria uma regressão?
- Como um consumidor descobre e confia nesse dataset?

## Sinais de prontidão para vaga júnior

O aluno não precisa saber tudo de memória. Está pronto quando consegue receber uma demanda pequena, quebrá-la em etapas, pesquisar documentação oficial, produzir código simples e testado, usar Git corretamente, pedir ajuda com contexto, proteger dados e operar o que construiu.
